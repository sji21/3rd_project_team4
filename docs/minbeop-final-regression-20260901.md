# 민법 후보 추가 최종 검색 회귀 결과 (2026-09-01)

## 결론

민법 최소 후보 5개 조문(제623·626·627·634·640조)을 **모든 질문에 항상 노출하는 방식은 채택하지 않는다.**

- dev 법령 성능은 유지됐다.
- 법령 holdout의 Hit@3·Recall@3도 유지됐지만, TOP3 구성이 4문항에서 바뀌고 정답 최초 순위가 1문항에서 2위→3위로 하락했다.
- holdout Recall@5는 정답 조문 기준 23/27→22/27로 하락했다.
- 민법 직접 질문 5개 중 4개만 정답 조문이 TOP3에 들었다.
- 판례 검색 결과는 민법 추가 전후 20문항 모두 순위가 동일했다.

따라서 민법은 수리·비용상환·사용불능·통지·차임연체처럼 의도가 확인된 질문에만 조건부로 노출하는 것이 안전하다.
