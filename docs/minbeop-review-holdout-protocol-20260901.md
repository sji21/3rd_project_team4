- 목적: 민법 후보 조문 추가의 개선 효과와 기존 법령 TOP3 오염을 확인한다.
- 용도: 민법 코퍼스·라우팅 결정용 실험 평가셋이다. 필수 산출물의 독립 최종 holdout으로 재사용하지 않는다.
- 질문 출처: 외부 AI가 생성하고 사용자가 원문 그대로 전달한 20문항
- 구성: A 7문항, B 8문항, C 5문항 / 기초 8, 중간 8, 까다로움 4
- 라벨 절차: 검색 결과를 실행하기 전에 저장소의 법령 원문을 기준으로 정답 조문과 보류 유형을 확정했다.
- 채점 대상: A·B 15문항. C 5문항은 검색 Recall과 분리하고 보류·범위 밖 처리용으로만 사용한다.

- 누락 탐지 문항: 14번은 최소 후보 5조에 없는 민법 제629조를 정답으로 한다.
