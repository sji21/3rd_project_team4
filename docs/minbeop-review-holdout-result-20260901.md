# 민법 추가 검토용 봉인 평가 결과 (2026-09-01)

## 결론

민법 조문을 법령 코퍼스에 **항상 노출하는 방식은 부적합**하다. 최소 5조 후보가 민법 질문의 검색률은 높였지만, 민법과 무관한 계약갱신 질문에서 기존 정답 조문을 TOP3 밖으로 밀어냈다. 6조·11조 확장은 추가 이득 없이 오탐과 후보 간 경쟁을 늘렸다.

현 단계의 채택안은 다음과 같다.

1. 민법은 기본 법령 검색에서 제외한다.
2. 수리·비용상환·사용불능·통지 등 민법 의도가 확인될 때만 별도 검색한다.
3. 최소 후보 5조만 우선 사용하고 제621조 및 2순위 조문은 보류한다.
4. 제629조 전대 질문은 별도 후보로 다시 평가한다.
5. 민법 검색 안에서도 제623·634조, 제627·640조가 서로 혼동되므로 용어 보강이나 민법 전용 소규모 리랭킹을 추가로 검토한다.

## 문항별 핵심 진단

### 개선

- 8번 보일러 수리: 민법 제623조 3위
- 9번 하자 통지: 민법 제634조 2위
- 12번 일부 사용불능과 차임 감액: 민법 제627조 1위
- 11번 선지출 수리비: 민법 제626조가 5위로 진입했으나 생성 TOP3에는 미포함
- 10번 월세 2개월 연체와 갱신 거절: 주택임대차보호법 제6조의3이 1위를 유지해 대조 문항은 통과

### 회귀·미해결

- 4번 묵시적 갱신: 기존 정답 주택임대차보호법 제6조가 3위에서 5위로 하락. 무관한 민법 제634조가 3위에 진입했다.
- 13번 수리 특약: 정답 후보 제623조는 TOP5 밖이고, 제634조가 1위로 잘못 진입했다.
- 14번 무단 전대: 최소 5조에 제629조가 없어 실패했다. 11조 확장에서도 제629조는 TOP5에 들지 못했고 제634·621·630조가 앞섰다.
- 15번 심각한 누수와 중도 해지: 정답 제627조는 TOP5 밖이고, 무관한 제640조가 4위에 진입했다.
- 8번은 제623조가 들어왔지만 제634조가 1위여서 민법 내부 순위도 완전히 안정적이지 않다.

## C 묶음 관찰

- 최소 5조에서는 C 5문항의 TOP3에 민법이 들어오지 않았다.
- 제621조를 더한 6조 구성은 특정 주택 안전판정 요청에 제621조가 TOP3로 진입했다.
- 11조 구성은 안전판정 요청 두 문항에서 제621조 또는 제629조가 TOP3로 진입했다.
- C 묶음의 최종 보류 성공 여부는 검색기가 아니라 생성·정책 계층에서 별도로 평가해야 한다.
