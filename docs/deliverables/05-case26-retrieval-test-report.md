# LENS 판례 26건 검색 테스트 결과서

## 1. 목적과 결론

현재 제출·시연 환경이 실제로 사용하는 판례 26건을 기준으로 검색 성능과 회귀 여부를
확인했다. 서비스 설정인 BM25 + KURE-v1 + RRF Hybrid는 기존 dev 매핑 13문항에서
Hit@2 92.3%, 외부 표현 8문항에서 Hit@2 87.5%를 기록했다. 상위 5건에서는 두 평가셋
모두 정답 판례를 100% 포함했다.

현재 생성 모델에는 판례 2건만 전달하므로 Hit@2를 운영 주 지표로 본다. 두 평가셋에서
각각 한 문항의 최초 정답이 2위 밖에 있어 조건부 통과로 판정한다. 다만 법령 근거는 별도
상위 3건으로 함께 전달되므로 이 결과는 판례 검색 범위만의 진단이며 답변 정확도와 동일한
수치가 아니다.

## 3. 평가셋

### 3.1 Dev 매핑 13문항

공통 dev 27문항 중 판례만으로 관련 근거를 찾을 수 있도록 기존에 지정된 13문항을 사용했다.
정답은 `scripts/load_case_only_demo_corpus.py`의 `question_ids`와 `case_id` 매핑으로 고정했다.

이 판례 요약문은 dev 질문을 참고해 작성되었으므로 dev 결과는 재현·회귀 확인용이다.
독립적인 일반화 성능이나 blind holdout 정확도로 해석하지 않는다.

### 3.2 외부 표현 8문항

민법·최종 holdout 검토 과정에서 외부 AI가 먼저 작성한 30문항 중 현재 판례 26건으로
근거를 연결할 수 있는 8문항을 골랐다. 검색 점수를 확인하기 전에 정답 `case_id`를 고정했고,
측정 후 검색 설정을 변경하지 않았다.

질문 표현은 기존 dev와 독립적이지만 코퍼스가 검증된 판례 원문이 아닌 평가용 요약문이므로
엄밀한 최종 holdout으로 부르지 않고 외부 표현 회귀셋으로 기록한다.

기존 `case_holdout_current_20.jsonl`은 별도 공식 판례 20건용이다. 현재 운영 26건과 정답
`case_id` 교집합이 0건이라 이번 평가에 혼합하지 않았다.

## 4. 결과

### 4.1 Dev 매핑 13문항

| 검색 방식 | Hit@1 | Hit@2 | Hit@3 | Hit@5 | MRR | 평균 Recall@2 | 평균 Recall@5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 기본 | 76.9% | 92.3% | 100.0% | 100.0% | 0.8718 | 48.0% | 71.0% |
| BM25 서비스 확장 | 84.6% | 100.0% | 100.0% | 100.0% | 0.9231 | 51.9% | 67.2% |
| Dense KURE-v1 | 92.3% | 92.3% | 92.3% | 92.3% | 0.9231 | 46.7% | 60.3% |
| **Hybrid 서비스 RRF** | **92.3%** | **92.3%** | **92.3%** | **100.0%** | **0.9423** | **46.1%** | **70.0%** |

### 4.2 외부 표현 8문항

| 검색 방식 | Hit@1 | Hit@2 | Hit@3 | Hit@5 | MRR | 평균 Recall@2 | 평균 Recall@5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 기본 | 62.5% | 75.0% | 75.0% | 87.5% | 0.7125 | 38.5% | 61.5% |
| BM25 서비스 확장 | 50.0% | 87.5% | 87.5% | 100.0% | 0.7125 | 41.7% | 57.3% |
| Dense KURE-v1 | **87.5%** | 87.5% | 100.0% | 100.0% | **0.9167** | 44.8% | 64.6% |
| **Hybrid 서비스 RRF** | 75.0% | **87.5%** | **100.0%** | **100.0%** | 0.8542 | **44.8%** | **75.0%** |

외부 표현에서는 Dense 단독의 Hit@1과 MRR이 Hybrid보다 높았다. 반면 Hybrid는 상위 5건의
전체 관련 판례 회수율이 가장 높았다. 따라서 Hybrid가 모든 지표에서 최고라고 주장하지 않고,
어휘 검색과 의미 검색의 실패를 상호 보완해 상위 5건 누락을 막는 구성으로 해석한다.

## 5. 실패 문항 분석

### 5.1 Dev case26-dev-020

- 질문: 등기를 하지 않은 전세계약도 주택임대차보호법의 보호를 받는지 묻는 문항
- Hybrid 최초 정답: 4위 `CASE-2000DA24184`
- 영향: 생성 모델에 전달하는 판례 2건에는 포함되지 않음
- 해석: 이 질문은 판례보다 주택임대차보호법 제12조가 직접 근거다. 실제 서비스는 법령 상위
  3건을 별도로 전달하므로 판례 누락만으로 답변 근거가 사라지지는 않는다.

### 5.2 외부 case26-ext-004

- 질문: 집이 팔려 주인이 바뀌면 계약을 다시 작성해야 하는지 묻는 문항
- Hybrid 최초 정답: 3위 `CASE-2011DA49523`
- 상위 1·2위: 실거주 갱신거절 판례가 먼저 반환됨
- 영향: 판례 2건 전달 계약에서는 직접 관련 판례가 잘림
- 후속 과제: 공식 판례 원문으로 교체한 뒤 양수인·임대인 지위 승계 표현을 포함한 독립 문항을
  추가하고, 판례 검색 확장 또는 리랭킹을 검토한다. 현재 요약 코퍼스에 맞춘 규칙은 추가하지 않는다.

## 6. 회귀·재현 확인

- 같은 입력과 설정으로 두 번 실행해 코퍼스 해시·파라미터·문항별 결과가 모두 동일했다.
- 판례 평가·검색 관련 자동 테스트 56개와 subtest 20개가 통과했다.
- 평가 실행은 운영 Chroma를 수정하지 않고 기존 `knowledge_chunks`를 읽기만 했다.
- 법령 133건과 안내 6건의 인덱스 범위는 변경하지 않았다.

## 7. 한계와 최종 판정

1. 판례 26건의 본문은 공식 판결요지·전문이 아니라 dev 질문을 참고해 작성한 쟁점 요약문이다.
2. 따라서 Hit@k 수치를 외부 데이터에 대한 판례 검색 정확도로 홍보하지 않는다.
3. 외부 표현 8문항도 공식 원문 코퍼스의 blind holdout을 대신하지 않는다.
4. 다수 정답 문항의 평균 Recall@2는 약 45%이지만, 생성에는 모든 유사 판례가 아니라 직접 관련
   판례 하나 이상이 필요하므로 운영 판단은 Hit@2를 우선한다.
5. 공식 판례 원문과 안정적인 case_id가 확보되면 코퍼스·정답 라벨을 교체해 다시 측정해야 한다.

현재 제출 범위에서는 **조건부 통과**로 판정한다. 운영 판례 26건의 적재·검색·출처 반환은
재현되며 Hybrid Hit@5는 두 평가셋 모두 100%다. 다만 생성 계약인 상위 2건 기준으로는 각각
1문항이 누락되므로, 보고서와 발표에서는 해당 한계와 판례 요약문 오염 사실을 함께 공개한다.
