## 5. 평가셋 운용 원칙

- Dev: 오류 분석과 설정 개선에 사용한다.
- 법령 Holdout: 설정 선택 후 퇴행 확인에 사용하며 재튜닝 근거로 사용하지 않는다.
- 판례 Holdout: 공식 판례 원문으로 라벨링된 별도 셋만 사용한다.
- 기관 안내: dev-017(국세청), dev-023(HUG)을 포함해 검색·생성·인용을 함께 확인한다.
- Holdout을 다시 열람하거나 재측정한 경우 횟수와 목적을 기록한다.
- 평가 질문을 보고 만든 판례 요약문은 성능 평가에서 제외하거나 오염 한계로 표시한다.

## 7. 실행 명령 묶음

```bash
pytest -q

python -m src.ingestion.validate_chunks \
  data/chunks/chunks.jsonl --eval-set data/eval/dev.jsonl

python -m src.evaluation.run_eval --run-id final-retrieval
python -m src.evaluation.compare_law_top3
python -m src.evaluation.run_generation_eval
```

실제 CLI 인자와 출력 경로는 최종 커밋에서 `--help`로 다시 확인하고 보고서에 복사한다.
