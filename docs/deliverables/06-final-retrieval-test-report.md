# LENS 법령·판례 검색 최종 테스트 결과서

## 1. 목적

현재 `main` 제출 환경에서 법령 검색과 판례 검색을 함께 재실행해 생성 모델에 전달되는
근거 범위 안에 정답이 들어오는지 확인한다. 생성 계약은 법령 상위 3건, 판례 상위 2건,
안내 조건부 0~2건이다.

이 보고서는 법령·판례 리트리버만 평가하며, 문서 업로드 OCR·질의응답 경로는 평가 범위에
포함하지 않는다.

## 2. 기준 환경

| 항목 | 값 |
| --- | --- |
| 기준 브랜치·커밋 | `main` · `7b1c3ab33e37c720766c762a18581ee3e864c25e` |
| Python | conda `jeonseon-test` · Python 3.11.16 |
| 임베딩 | `nlpai-lab/KURE-v1` |
| 통합 인덱스 | `data/index/chroma_kurev1_1024` |
| 코퍼스 | 법령 133청크 · 판례 26청크 · 안내 6청크 |
| 검색 | BM25 + Dense + RRF |
| 법령 설정 | `rrf_k=5`, 법령 문맥 확장, 생성 전달 3건 |
| 판례 설정 | `rrf_k=60`, 후보 깊이 20, 생성 전달 2건 |

## 3. 평가 계획

### 법령

- `dev.jsonl` 27문항 중 현재 법령 코퍼스에 정답 조문이 있는 24문항을 채점한다.
- 기존 `holdout.jsonl` 20문항을 사용한다.
- 점수 확인 전에 범위 밖으로 판정한 `holdout-006`, `holdout-009`를 제외해 18문항을 채점한다.
- Hit@3과 Recall@3을 생성 근거 계약의 핵심 지표로 본다.
- 이 셋은 이미 공개·재측정됐으므로 이번 수치는 새로운 blind holdout 성능이 아니라 현재
  `main`의 최종 회귀 확인이다.

### 판례

- 운영 코퍼스 26건과 연결된 dev 13문항으로 재현·회귀를 확인한다.
- 별도의 독립 holdout이 없어 외부 AI가 먼저 작성한 질문 중 정답 `case_id`를 사전에
  고정할 수 있었던 외부 표현 8문항을 **holdout 대체 평가셋**으로 사용한다.
- 생성 전달 계약에 맞춰 Hit@2를 주 지표로 보고 Hit@5를 진단 지표로 함께 기록한다.
- 26건 본문은 dev 질문을 참고해 작성한 요약문이므로 독립적인 판례 일반화 성능으로
  해석하지 않는다.

법령 Dev는 최종 서비스 기준 상위 3건에 24문항의 모든 정답 조문을 확보했다. 이 셋은
RRF 값과 문맥 확장 규칙 선택에 사용했으므로 일반화 평가가 아니라 개발·회귀 지표다.
법령 문맥 확장으로 순위가 바뀐 것은 `dev-001` 한 문항의 정답 조문 하나이며, 기존
holdout 18문항에서는 순위·지표 변화가 없었다. 관찰 42문항 중 한 문항에만 발동한 규칙이므로
독립 질문에서 재검증하기 전까지 일반적인 성능 개선으로 해석하지 않는다.

기존 PATCH-020·024 기록과 Hit 지표가 동일하다. RRF 5는 Hit 지표를 떨어뜨리지 않으면서
Recall@5와 MRR을 소폭 개선했다. 법령 상위 3건 기준 18문항 중 17문항에서 정답 조문을
하나 이상 확보했다.

### 법령 실패

`holdout-004`의 질문은 “전입신고와 확정일자는 계약한 날 바로 받아야 하나요?”이고 정답은
제3조와 제3조의2다. 현재 최종 서비스에서는 두 조문이 각각 7위와 9위다. “확정일자”라는
단어로 인해 제3조의6 및 시행령의 절차 조문이 먼저 올라온다. 이미 공개된 holdout 한 문항에
맞춘 규칙은 추가하지 않고 후속 독립 질문에서 재검증한다.

## 6. 판례 Dev 결과

### Dev 매핑 13문항

| 검색 방식 | Hit@1 | Hit@2 | Hit@3 | Hit@5 | MRR | Recall@5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 기본 | 76.9% | 92.3% | 100.0% | 100.0% | 0.8718 | 71.0% |
| BM25 서비스 확장 | 84.6% | 100.0% | 100.0% | 100.0% | 0.9231 | 67.2% |
| Dense KURE-v1 | 92.3% | 92.3% | 92.3% | 92.3% | 0.9231 | 60.3% |
| **Hybrid 서비스 RRF** | **92.3%** | **92.3%** | **92.3%** | **100.0%** | **0.9423** | **70.0%** |

운영 핵심 지표인 Hit@2에서는 BM25 서비스 확장이 100.0%로 Hybrid 92.3%보다 높다.
Hybrid는 Hit@2 최적 방식이라서가 아니라 MRR과 Recall@5, 어휘·의미 검색 결합을 함께
고려한 현재 서비스 구성이다. 독립 평가셋에서 운영 Hit@2 우월성은 다시 확인해야 한다.
Dense 단독의 Hit@1~Hit@5가 모두 92.3%인 것은 한 문항의 정답을 상위 5건에서도 찾지
못했다는 뜻이며, Recall@5도 60.3%로 네 방식 중 가장 낮다. n=13에서는 한 문항이 약
7.7%p이므로 소수점 한 자리 차이를 정밀한 우열로 해석하지 않는다.

## 7. 판례 Holdout 대체 평가 결과

### 외부 표현 8문항

| 검색 방식 | Hit@1 | Hit@2 | Hit@3 | Hit@5 | MRR | Recall@5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 기본 | 62.5% | 75.0% | 75.0% | 87.5% | 0.7125 | 61.5% |
| BM25 서비스 확장 | 50.0% | 87.5% | 87.5% | 100.0% | 0.7125 | 57.3% |
| Dense KURE-v1 | 87.5% | 87.5% | 100.0% | 100.0% | 0.9167 | 64.6% |
| **Hybrid 서비스 RRF** | **75.0%** | **87.5%** | **100.0%** | **100.0%** | **0.8542** | **75.0%** |

n=8에서는 한 문항이 12.5%p이므로 방식 간 차이는 방향을 확인하는 참고값으로만 본다.

Dense 단독은 외부 표현 Hit@1과 MRR이 Hybrid보다 높다. Hybrid는 모든 지표에서 최고인
모델이 아니라, 어휘·의미 검색을 결합해 외부 표현의 Hit@3·Hit@5와 Recall@5를 안정적으로
확보하는 현재 서비스 구성이다.

### 판례 상위 2건 누락

- `case26-dev-020`: 정답 판례 4위. 질문의 직접 근거인 주택임대차보호법 제12조는 법령
  검색에서 별도로 제공된다.
- `case26-ext-004`: 집주인 변경·계약 재작성 질문의 직접 판례가 3위다. 상위 1·2위에는
  실거주 사유 갱신거절 판례가 올라왔다.

두 실패를 보고 질의 규칙이나 리랭킹을 추가하지 않았다. 26건 요약 코퍼스의 소수 문항에
맞춘 과적합을 피하고 공식 판례 원문 전환 후 재평가하기 위한 결정이다.

## 9. 최종 판정

**조건부 통과**로 판정한다.

- 법령은 생성에 전달되는 상위 3건에서 18문항 중 17문항의 정답을 확보했다.
- 법령 Dev는 상위 3건에서 24문항 모두 정답을 확보했다.
- 판례 Hybrid는 상위 2건에서 dev 12/13, 외부 표현 7/8의 정답을 확보했고 상위 5건에서는
  두 셋 모두 100%였다.
- 현재 서비스 계약인 법령 3건 + 판례 2건을 유지할 수 있다.
- 법령 holdout은 이미 공개된 회귀셋이고, 판례 26건은 dev 기반 요약 코퍼스이므로 두 결과를
  합산한 단일 “전체 정확도”는 만들지 않는다.
- 후속 과제는 공식 판례 원문 코퍼스와 독립적으로 봉인한 판례 holdout 평가다.
- 법령 문맥 확장과 Hybrid 채택의 운영상 우월성은 현재 표본만으로 확정하지 않고 독립
  평가셋에서 재검증한다.
