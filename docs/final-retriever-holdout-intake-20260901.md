# 최종 후보 평가셋 접수 기록

## 상태

- 질문 원문 접수 및 raw 봉인 완료
- raw SHA-256: `b8f4556efbe3828f9472c2f5efa937bbd8584c66b9c0097305412fff3082c82f`
- 정답 라벨링 전
- 검색 실행 전
- 최종 검색 설정 확정 전이므로 점수 측정 보류
- 질문 원문을 민법 조건부 라우팅 확정 전에 확인했으므로 엄밀한 blind holdout은 아님
- 이 30문항은 설정 고정 후 확인용으로만 쓰고, 최종 일반화 평가는 새 비공개 문항으로 수행

## 원본 구성 점검

- 전체: 30문항
- 묶음: A 15, B 6, C 4, D 5 — 요청과 일치
- 난이도: 기초 12, 중간 13, 까다로움 5 — 요청한 12/12/6과 불일치
- 질문 원문과 생성자가 부여한 묶음·난이도는 수정하지 않고 `source_*` 필드로 보존

## 사전 검토 메모

- 1번과 19번은 모두 기간 중 퇴거 문제를 다루므로 의미 중복 여부를 라벨 단계에서 검토한다.
- 1번은 조문만으로 단정하기 어려워 판례·계약 해석형으로 재분류될 수 있다.
- 9번은 확정일자와 전세권을 비교하므로 현재 코퍼스에 전세권 근거 조문이 없으면 부분 범위 밖으로 분류한다.
- 10번과 15번은 보증금 미반환이라는 공통점이 있지만, 이사 전과 이미 이사한 후라는 상태가 달라 별도 문항으로 유지한다.
- B 묶음은 현재 판례 코퍼스의 안정적인 `case_id`와 실제 연결되는지 확인한 뒤에만 판례 검색 지표 분모에 포함한다.
- 사전 원문 대조 결과, B 6문항의 도배 약속·누수 손해·원상회복·중도 퇴거·공사 소음·곰팡이 책임 쟁점은 현재 서비스 판례 26건과 직접 일치하지 않는다. 이 문항들은 판례 검색 Hit 분모에 억지로 넣지 않고 `out_of_corpus` 후보로 둔다. 판례 자체 정확도는 정답 `case_id`가 연결된 기존 판례 전용 holdout 20문항으로 별도 보고한다.
- C 묶음은 법령이 아니라 공식 안내 검색으로 별도 채점한다.
- D 묶음은 검색 Hit 지표가 아니라 보류·범위 밖 처리 지표로 채점한다.

## 다음 단계

1. A 법령 정답, B 판례 `case_id`, C 안내 문서, D 보류 사유를 검색 결과 확인 전에 라벨링한다.
2. 라벨 불명확·코퍼스 범위 밖 문항을 사전에 구분한다.
3. 최종 민법 라우팅과 코퍼스 구성을 확정한다.
4. 라벨 파일을 별도 SHA-256으로 봉인한다.
5. 이 30문항은 확정 설정의 확인용 결과로 별도 기록한다.
6. 새 비공개 문항을 생성·라벨 봉인한 뒤 최종 일반화 평가를 한 번만 수행한다.
